# needtopee.app

Website for the [Nice to pee](https://needtopee.app) app: home page, privacy policy and terms of use. GitHub Pages serves this repo's `main` branch at https://needtopee.app (custom domain set in `CNAME`).

Edit the HTML and push to `main` to publish. `/privacy` and `/terms` resolve to `privacy.html` and `terms.html`.
